# 42. The website

Part of [Qutai: how it works and the decisions behind it](../../DESIGN.md) · [All decisions](decisions-index.md) · [History](history.md)

Qutai's marketing site lives in `webpage/`, a separate project inside this repository. It describes the app, compares it with other mobile browsers, shows the app's privacy policy, and hosts the page that the sign-in email's link opens.

## How it works

1. The site is a long home page in English (`/en/`) and Turkish (`/tr/`), plus a features page (`/en/features/`, `/tr/features/`). It is written in React, turned into static HTML at build time, and served by Cloudflare Workers. A small Worker answers only `/` (and `/features`, `/privacy-policy`, `/terms`, `/delete-account`, `/support`): it sends the visitor to `/en/` or `/tr/` by the `lang` cookie, then by the browser's language, and otherwise to English.
2. The page has these parts: the hero, a statement beside a phone mock drawn from the app's own strings and colours, scenarios, memory, privacy, the browser, a comparison table with eight mobile browsers, getting started, open source, status, and the footer. The illustrations are robot "miniature" paintings (`webpage/ART.md`).
3. **Features page** (`/<lang>/features/`, static, no script): every feature in ten groups written from this design record (`webpage/src/data/features.ts`), each with example requests to the assistant; the principles, "What leaves the phone", and the "Deliberately not built" list. Its picture is an illuminated medallion drawn in SVG (Qutai's mark in the centre, one petal per group, each a link to its group). The header, the footer and the home page's browser section link to it.
4. The app's privacy policy has its own pages (`/en/privacy-policy/`, `/tr/privacy-policy/`), and so do its terms of use (`/en/terms/`, `/tr/terms/`, `WEB-14`). The texts are copied from the store build's documents (`src/legal/proDocuments.ts`) with `npm run legal`, and `npm run check` fails when a copy no longer matches the app.
5. `/intent/sign-in/email?token=…` is where the sign-in email links, because mail apps such as Gmail don't make a `qutai://` link tappable. On a phone the page opens Qutai once by itself and always shows an "Open Qutai" button. On a computer it says the link is for the phone. It signs nothing in, removes the token from the address bar, and logs nothing. The Worker also serves the App Link and Universal Link files (404 until they are set up).
6. The site loads nothing from other websites (no fonts, analytics or CDNs), and its only cookie is `lang`.
7. When an app feature lands, a session updates the site, the features page and the comparison column, for example d14bd7a, 0d51a9e, 2767fae, 3dc3119 and 441b6d1.

## The rules

- **`WEB-1`** The website states only true facts about the app. Qutai's comparison column follows the code and the owner's checklist, and missing features (sync, desktop, store release today) stay "no".
  Status: Default (manager or implementing session; open to change) · Why: "Keep it honest". The paid Qutai service is described as it is, not as "not offered yet" (0d51a9e) · Source: webpage/README.md › Updating the comparison; 33e911e ("an honest status")
- **`WEB-2`** Each competitor cell comes only from the vendor's own current pages about its mobile app, with the URL and the date it was checked. A cell no such page settles is "unknown" and shows as "Not confirmed", never "No". A desktop-only feature is "no" with a note, and notes are in our own words, never copied text.
  Status: Default (manager or implementing session; open to change) · Why: claims about competitors must be checkable and fair · Source: webpage/README.md › Updating the comparison; 670c6dd, a988ff9
- **`WEB-4`** Other products' names appear in plain text only, without logos or brand colours. A "Report a correction" link goes to the repository's issues.
  Status: Default (manager or implementing session; open to change) · Why: product names are their owners' trademarks · Source: webpage/README.md
- **`WEB-5`** The site makes no requests to other websites, and its only cookie is `lang`, which the language switch sets.
  Status: Default (manager or implementing session; open to change) · Why: the privacy story of the app applies to its site too · Enforced: In the app: webpage `npm run check` (fails on any third-party load), `_headers` Content-Security-Policy · Source: webpage/README.md › Privacy of the site itself
- **`WEB-6`** The site's privacy policy is the app's own store-build text, never edited on the site. After the app's policy changes, someone runs `npm run legal` and rebuilds.
  Status: Default (manager or implementing session; open to change) · Why: one source for the policy. This replaced a link to a .ts file on GitHub · Enforced: In the app: webpage `npm run check` (fails when the copy differs) · Source: 06b800c
- **`WEB-7`** The sign-in link page never uses up the one-time token, signs nothing in, removes the token from the address bar and history, and logs nothing. It answers with no-store, no-referrer, noindex and its own Content-Security-Policy.
  Status: Default (manager or implementing session; open to change) · Why: the token is a single-use sign-in secret, so a mail scanner opening the link must not use it up · Enforced: In the app: webpage/worker/intent.ts · Source: 2a06fbd
- **`WEB-8`** Demo videos are real recordings made on brand-free demo sites, under written honesty rules. Qutai is pronounced "Kutay", and Turkish suffixes follow that pronunciation (Qutai’ı, Qutai’a, Qutai’ın).
  Status: Default (manager or implementing session; open to change) · Why: reason not recorded beyond honesty and correct pronunciation · Source: dd36792, 52347da, 8460500
- **`WEB-9`** The brand line and page title are "Qutai: Agentic Browser". The site always uses the light parchment look and has no Trademarks links.
  Status: Default (manager or implementing session; open to change) · Why: reason not recorded · Source: 3ea22b7, eb6e651, f25fa0b, a1d1ca6

Comparing products across tabs and reading PDFs are no longer headline features there (both are still on the features page).   Status: Owner, 2026-11-26 ("sizi tanır, formları doldurur, araştırmalar yapar vs gibi daha agentic şeylerle dolduralım ana sayfayı") · Why: the home page should show an agent, not a comparison tool · Enforced: In the app: webpage/src/i18n/{en,tr}.ts (`hero.*`, `statement.text`, `agent.*`, `mock.*`), webpage/src/components/Sections.tsx (`SCENARIOS`, hero chips), webpage/src/components/PhoneMock.tsx
- **`WEB-17`** The site is written to be found by search engines and AI answers (SEO and GEO). It has a guide, "What is an agentic browser?" (`/en/agentic-browser/`, `/tr/agentic-browser/`), whose short answers carry FAQPage structured data, and a "Qutai vs …" page for each competitor in the comparison table (`/<lang>/vs/<id>/`). Those pages are built only from the table: every row, with notes, and each competitor cell's source or "our own test" (`WEB-2`). The home page's comparison and the footer link to them. `/llms.txt` gives AI assistants a plain-text summary of the site, including the app's ten interface languages (`LANG-1`, each named in English and in itself; the home page has a "Ten languages" tile and the features page says the assistant answers in the language you write in, `LANG-7`; voice input languages are not claimed). AI crawlers are allowed (`robots.txt` allows everything; checked 2026-11-26 that GPTBot, ClaudeBot, PerplexityBot, Google-Extended, OAI-SearchBot and CCBot get the pages). Competitor names appear only on the comparison pages, never in the store listing (Play's metadata rules; docs/marketing/play-listing.md).
  Status: Owner, 2026-11-26 ("SEO ve GEO… AI browser, agentic browser gibi şeylerde sorulara cevap olabilelim… perplexity comet sorarsa biz de çıkalım") · Why: people ask search engines and AI assistants for AI and agentic browsers by name and by competitor · Enforced: In the app: webpage/src/data/guide.ts, webpage/src/components/SeoPages.tsx, webpage/scripts/prerender.mjs (pages, llms.txt, JSON-LD, sitemap), webpage `npm run check` (guide with FAQ data, every vs page, links from home, sitemap, llms.txt, offer price 0)

## Details

Why: the owner's request (19 Nov 2026): the formal form sounded unnatural in a request. Where: webpage/src/data/features.ts.
