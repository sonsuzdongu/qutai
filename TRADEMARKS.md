- Build and run the code for your own personal use, development and testing without changing the name

## If you publish a fork

Before you distribute it, give it its own identity:

1. Choose a different name and change it everywhere it appears: `app.json` (`name`, `slug`), the UI strings
   in `src/i18n/` and `locales/`, the README, and the legal texts in `src/legal/documents.ts` (which also
   describe our privacy practices; write your own)
2. Replace the logo and all icons listed above with your own
3. Use your own bundle identifier and Android package name
4. Use your own server and accounts if you enable any server features; do not point a fork at Qutai's
   servers in a way that suggests it is the official app
